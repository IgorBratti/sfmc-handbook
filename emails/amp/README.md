# Interactive AMP emails

Interactive AMP for Email templates, where users act inside the email without leaving the inbox:

- Spin-to-win discount
- Coupon reveal
- Interest update (preference form inside the email)
- Cart items preview

Each template lives in its own folder with:

- `amp.html`: the AMP version
- `fallback.html`: the regular HTML version for clients that don't support AMP
- `demo.gif`: a short recording of the interaction

Note: to send AMP emails to Gmail you need sender registration with Google. Marketing Cloud sends the AMP part through the AMP for Email content type in Content Builder.
