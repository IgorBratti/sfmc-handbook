# AMPscript recipes

Short, copy-ready recipes for emails and CloudPages. Each file groups recipes by theme.

| Recipe file | What's inside |
|---|---|
| [personalization.md](personalization.md) | Fallbacks for empty fields, proper case, content by segment |
| [dates.md](dates.md) | Local time, adding days, days until a date, formats by language |
| [lookups-and-loops.md](lookups-and-loops.md) | `Lookup`, `LookupOrderedRows`, loops, building lists |
| [links-and-cloudpages.md](links-and-cloudpages.md) | Tracked links, encoded parameters, `CloudPagesURL` |
| [strings-and-numbers.md](strings-and-numbers.md) | Cleaning text, splitting names, currency and number formats |
| [send-control.md](send-control.md) | Skipping the send for one contact with `RaiseError` |

Related: [field notes on AMPscript](../field-notes/ampscript.md) (the traps) and [CloudPages](../cloudpages/) (full examples).
